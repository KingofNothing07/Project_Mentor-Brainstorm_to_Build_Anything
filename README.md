# Project Mentor — Brainstorm to Build Anything

**An honest, one-question-at-a-time design partner that turns messy ideas, notes, or half-finished work into an approved, agent-ready project log shaped as a knowledge graph.**

Drop this skill into any AI that supports custom skills or system prompts. It captures brainstorms, scopes the work, surfaces gaps, builds a living knowledge graph with forward and reverse flowcharts, and either builds from the log or hands off a clean **inheritance package** that any other AI or agent can continue from. Only what you approve is binding.

Works for code, systems, businesses, writing, research, trading strategies, 3D models, video, games, skills themselves, and anything else. From a single script to a multi-module product.

## Why Project Mentor?

Most AI chats wander. This one keeps a structured, versioned, agent-readable log:

- **Knowledge graph** with typed edges (`flows-to`, `depends-on`, `interfaces-with`, …)
- **Forward flowchart** (what happens) and **reverse flowchart** (what must exist first — the build order)
- **One question at a time**, highest-leverage first
- **Approved deltas only** — nothing changes without your explicit yes
- **Domain modes** (Build, Venture, Writing, Research & Science, Trading & Quant, 3D & Mesh, Video & YouTube, Systems Designer, Hardware, Creative Media, and custom modes you can create)
- **Inheritance packages** that let other AIs pick up the exact approved design without re-explaining everything
- **Work-in-progress intake** for diagnosing and finishing existing projects

It is deliberately opinionated about honesty and completeness, and deliberately flexible about structure.

## Quick Start

1. Copy `SKILL.md` into your AI’s skill folder (or paste the body as custom instructions).
2. Say something like:
   - “Mentor me on this project.”
   - “Help me plan, scope, and flesh this out.”
   - “What am I missing?”
   - “Poke holes in my plan.”
   - “Turn this into a skill.”
   - “Help me finish this half-built thing.”
   - “Resume my project log.”
3. Answer one question at a time. Approve or reject the proposed deltas. When the log is finishable, ask for the package or a builder pass.

The skill states its proposed load path (Capture / Lite / Full) and mode with the first question. You can change either at any time.

## What You Get

| Stage | Outcome |
|-------|---------|
| Capture | Organized idea notes, clustered into modules |
| Root | Clear purpose, success criteria, constraints, overall flow |
| Map | Modules, edges, coverage checklist run |
| Detail | Sections, decisions, acceptance tests, exact values |
| Audit | Contradictions, gaps, reverse-flowchart blockers surfaced as deltas |
| Package | Inheritance document + Approved Log + files + manifest + Director brief |
| Build or hand-off | Working artifacts or prompts ready for other agents |

Everything is plain text. It works with any AI. Tool and product names inside the skill are examples, never dependencies.
